# 移动端输入区状态入口收敛设计

## 背景
- 手机端输入区底部状态元素过碎，分支、额度、上下文压缩各自占位，视觉节奏不统一。
- 现状会在小屏上产生拥挤和换行风险，分支管理入口也比移动端所需信息密度更重。

## 目标
- 移动端将状态区收敛为单行布局。
- 分支管理只保留图标入口，但继续复用现有完整分支面板能力。
- 将剩余额度与背景信息窗口入口合并，减少零散控件。
- 保留桌面端现有结构，避免无关回归。

## 方案
### 分支入口
- 在 `<=720px` 时，把分支按钮压缩成纯图标圆按钮。
- 点击后仍打开现有分支底部面板，不修改分支切换、创建、推送逻辑。

### 额度与背景信息入口
- 新增移动端统一状态入口，外观为单个紧凑胶囊。
- 入口内主信息展示两个额度窗口的紧凑摘要，优先将“周”和“小时”并列呈现。
- 右侧展示背景信息窗口状态，用更弱的色块和小圆点提示风险级别，避免视觉噪声。

### 统一面板
- 点击统一入口后，打开一个底部面板。
- 面板上半部分展示额度窗口明细与 AI Credits。
- 面板下半部分展示背景信息窗口占用、标记统计、自动压缩提示和“立即压缩”操作。

## 约束
- 桌面端不改现有 hover popover 行为。
- 只调整 `ThreadComposer` 的模板、状态和样式，不改协议和业务逻辑。

## 验证
- 执行 `npm run build`。
